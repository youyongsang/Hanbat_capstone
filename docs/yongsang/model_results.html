01 정확도 vs 지연 — 한 장

네 모델의 정확도는 오차범위 안에서 겹친다(세로 폭, Baseline 근소 선두). 갈리는 건 지연(가로). EE Fixed는 Baseline 대비 −28%, per-exit로는 SDN보다 전 stage 가벼움 — SDN 평균이 더 낮은 건 캘리브레이션 T=0.72가 exit1을 앞당긴 것. Proposed의 가치 주장이 "정확도"가 아니라 "속도·효율 + 트래픽 적응형 임계값"인 이유. (전부 window 12 — 정확도 5시드, 지연 Pi INT8 실측 2026-09-02, k2m2 게이트.)

04 Early Exit 종료 지점 분포

Baseline은 조기종료가 없어 항상 exit 3(3개 LSTM 층 전부). Proposed·SDN은 대부분 exit 1~2에서 끝난다 — 이게 속도·연산량 이득의 실체. Dynamic θ는 Fixed보다 더 얕게 빠지고(exit 3 도달 12.3%), SDN은 T=0.72라 exit 1에서 37.3% 종료. (window 12, k2m2 게이트, 배포 체크포인트 기준.)
