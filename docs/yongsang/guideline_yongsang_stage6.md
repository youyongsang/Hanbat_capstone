## 3. 발표 슬라이드 담당 파트

### 담당 슬라이드

| 슬라이드 | 내용 |
|---|---|
| Early Exit 개념 설명 | "필요한 만큼만 계산한다" |
| 시스템 흐름도 | 3단계 파이프라인 |
| 고정 θ 결과 | Exit 종료율, 추론 시간 |
| 동적 θ 분석 | 고정 대비 비교, 한계, 향후 과제 |

### 발표 멘트 준비

**Early Exit 개념 슬라이드:**
> "일반 LSTM은 매번 모든 레이어를 통과합니다. Early Exit은 각 레이어 후 Entropy를 계산하여 충분히 확신되면 여기서 종료합니다. 정상 구간의 70% 이상에서 Exit 1에서 종료하여 평균 추론 시간을 크게 줄일 수 있습니다."

**동적 θ 분석 슬라이드:**
> "동적 threshold는 트래픽 변동률에 따라 θ를 실시간 조정합니다. Exit 1 종료율이 고정 θ 대비 일관되게 높아졌으나, 변동률 계산 오버헤드로 인해 실측 추론 시간은 오히려 증가했습니다. 이는 현재 구현의 한계이며, 경량 계산 방식으로 개선 가능합니다."

## 4. 예상 질문 및 답변 준비

### 교수님 예상 질문

**Q1. Early Exit을 왜 굳이 쓰냐? 그냥 작은 모델 쓰면 되지 않냐?**
> "작은 모델을 고정으로 쓰면 복잡한 혼잡 패턴에서 정확도가 떨어집니다. Early Exit은 같은 3레이어 모델에서 상황에 따라 연산 깊이를 조절합니다. 정상 구간에서는 빠르게, 혼잡 구간에서는 정확하게 동작하는 구조입니다."

**Q2. 동적 threshold가 오히려 느린데 의미가 있냐?**
> "현재 구현에서 오버헤드 문제를 확인했습니다. Exit 1 종료율은 일관되게 높아 잠재적 이득은 있으나 계산 비용이 이를 상쇄했습니다. max-min 범위 기반 경량 계산이나 주기적 업데이트로 오버헤드를 줄이는 것이 향후 개선 방향입니다."

**Q3. 단순히 있는 기술 갖다 붙인 거 아닌가?**
> "Early Exit 자체는 기존 기술이지만, 트래픽 혼잡 분류 태스크에 적용한 사례가 없었습니다. 또한 동적 threshold를 무선 트래픽 변동률과 연결하는 설계는 기존 연구에서 다루지 않은 부분입니다. 기술 조합 과정에서 발생하는 새로운 설계 문제를 정의하고 실험으로 검증한 것이 기여입니다."
