# 유용상 방학 5단계 가이드라인
## 호중 배포 실험 연동 및 최종 분석 정리

> 담당자: 유용상  
> 목표: 검증된 모델 코드와 threshold 설정을 호중 배포 실험에 전달하고 최종 비교 분석 정리  
> 완료 기준: PC 기준 모델 결과와 Pi 배포 결과를 연결한 분석 문서 완성

---

## 1. 해야 할 일 순서

```
1. 최종 모델 구조 변경사항 정리
2. 최종 threshold 파라미터 정리
3. PC 기준 fixed/dynamic/경량 dynamic 결과 정리
4. 호중에게 ONNX 변환 대상 코드와 설정 전달
5. 호중 Pi 결과와 용상 PC 결과 비교 분석
```

---

## 2. 전달 항목

| 항목 | 설명 |
|---|---|
| 모델 구조 변경사항 | Early Exit LSTM 코드 변경 여부 |
| 최종 threshold 설정 | 고정 θ, 동적 θ 초기값, spike 기준 |
| 실측 데이터 PC 결과 | 정확도, 추론 시간, Exit 비율 |
| 권장 실험 명령어 | 호중이 ONNX/INT8 변환 시 사용할 실행 순서 |

---

## 3. 완료 기준 체크리스트

- [ ] 최종 모델 코드 커밋
- [ ] threshold 설정값 문서화
- [ ] PC 기준 결과표 작성
- [ ] 호중에게 ONNX 변환 대상 코드 전달
- [ ] 호중 Pi 결과와 용상 PC 결과 비교 분석

---

## 4. 주의사항

- 용상 브랜치에서 Pi 체크포인트나 ONNX 결과를 직접 관리하지 않는다.
- Pi 실측 성능은 호중 결과를 기준으로 인용한다.
- 용상 브랜치에서는 PC 기준 모델 재검증에 집중한다.
