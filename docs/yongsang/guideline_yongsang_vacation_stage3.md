# 유용상 방학 3단계 가이드라인
## 동적 Threshold 경량화 개선

> 담당자: 유용상  
> 목표: 기존 동적 threshold 계산 오버헤드를 줄이는 경량화 방식 구현  
> 완료 기준: max-min, 주기적 업데이트, 조합 방식 비교 결과 작성

---

## 1. 기존 문제

```text
std 기반 계산
→ 매 타임스텝 제곱근 연산 발생
→ Exit 비율 개선 이득보다 동적 θ 계산 오버헤드가 커질 수 있음
```

---

## 2. 개선안

| 방식 | 설명 | 기대 효과 |
|---|---|---|
| max-min 범위 | `std` 대신 `max(window) - min(window)` 사용 | 제곱근 연산 제거 |
| 주기적 업데이트 | 매 시점이 아니라 K 시점마다 θ 갱신 | 계산 횟수 감소 |
| 조합 방식 | max-min + 주기적 업데이트 | 오버헤드 최소화 |

---

## 3. 구현 예시

```python
if timestep % 3 == 0:
    variance = max(recent_window) - min(recent_window)
    theta_1, theta_2 = adjust_threshold(variance)
```

---

## 4. 완료 기준 체크리스트

- [ ] max-min 기반 경량 동적 θ 구현
- [ ] 주기적 업데이트 방식 구현
- [ ] 조합 방식 구현
- [ ] 기존 동적 θ와 결과 비교
- [ ] 고정 θ와 경량 동적 θ 결과 비교

---

## 5. 주의사항

- 동적 θ가 항상 고정 θ보다 빠르게 나와야 하는 것은 아니다.
- 정확도, Exit 분포, 급변 구간 대응력까지 같이 해석한다.
- threshold 파라미터를 바꾸면 반드시 값과 이유를 문서화한다.
