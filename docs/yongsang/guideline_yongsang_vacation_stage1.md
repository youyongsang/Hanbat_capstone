# 유용상 방학 1단계 가이드라인
## 실측 데이터 입력 형식 및 모델 재학습 준비

> 담당자: 유용상  
> 단계 목표: 실측 WiFi 데이터가 들어왔을 때 모델 재학습을 바로 수행할 수 있도록 입력 기준과 코드 상태 확인  
> 완료 기준: 기존 dataloader, 학습 스크립트, 비교 스크립트 준비 완료

---

## 1. 방학 1단계 공통 목표

1단계는 세 명 모두 실제 실험에 들어가기 전 준비 단계다.  
이 단계에서는 아직 본 실험 결과를 만들지 않고, 장비·데이터 형식·실험 기준을 맞춘다.

| 담당 | 1단계 역할 |
|---|---|
| 장예나 | 실측 테스트베드와 데이터 수집/라벨링 기준 확정 |
| 김호중 | Pi 실행 환경과 배포 스크립트 실행 준비 |
| 유용상 | 실측 데이터 입력 형식과 모델 재학습 준비 |

---

## 2. 해야 할 일 순서

```
1. 실측 CSV 필수 컬럼 확인
2. dataloader 입력 피처 순서 확인
3. window_size=10 구조 확인
4. train.py, train_early_exit.py 실행 조건 확인
5. compare_baselines.py 평가 항목 확인
```

---

## 3. 확인 기준

| 항목 | 기준 |
|---|---|
| 필수 컬럼 | `timestamp`, `rps`, `channel_occupancy`, `packet_loss`, `latency`, `label` |
| 입력 피처 | `rps`, `channel_occupancy`, `packet_loss`, `latency` |
| 라벨 | 0/1/2/3 |
| 윈도우 | 최근 10개 시점 기준 `(10, 4)` |

---

## 4. 완료 기준 체크리스트

- [ ] dataloader 입력 컬럼 확인
- [ ] 학습 스크립트 실행 경로 확인
- [ ] 비교 스크립트 실행 경로 확인
- [ ] 실측 데이터가 들어오면 확인할 shape 기준 정리
- [ ] 체크포인트/ONNX는 호중 산출물과 분리 관리 원칙 확인

---

## 5. 주의사항

- 1단계에서는 실측 데이터가 없어도 코드 준비를 끝낼 수 있어야 한다.
- 라벨 기준은 예나 문서의 기준을 따른다.
- Pi용 ONNX와 실측 Pi 결과는 호중 담당 산출물이다.
