## I. 서론

무선랜(WLAN)은 스마트 기기 보급 확산과 함께 실내 데이터 트래픽의 핵심 전송 매체로 자리 잡았으며, 이에 따라 AP(Access Point) 단위의 채널 혼잡은 사용자 체감 품질(QoS) 저하를 유발하는 주요 요인으로 지목되고 있다. 특히 다수의 단말이 동일 채널을 공유하는 환경에서는 채널 점유율 상승, 재전송 증가, 신호 품질 저하가 복합적으로 작용하여 혼잡 수준이 급격히 변화하므로, 이를 실시간으로 판단하고 채널 전환과 같은 대응을 트리거할 수 있는 엣지 기반 추론 체계가 요구된다.

혼잡 수준을 실시간으로 판단하기 위한 딥러닝 기반 접근으로는 조기 종료(Early-Exit) 신경망이 대표적이다. Teerapittayanon 등[1]이 제안한 BranchyNet을 시작으로, Kaya 등[2]은 내부 분류기(internal classifier)와 커리큘럼 기반 손실 함수를 결합한 Shallow-Deep Network(SDN)를 제안하여 추론 비용을 큰 폭으로 절감하면서도 정확도를 유지할 수 있음을 보였다. 그러나 이러한 조기 종료 기법은 주로 이미지 분류 태스크에서 검증되었으며, 무선 네트워크의 시계열 텔레메트리에 적용되어 엣지 장비에서 실측 지연까지 검증된 사례는 확인되지 않는다.

한편 WiFi 트래픽 및 혼잡을 예측하기 위한 딥러닝 연구도 다수 보고된 바 있다. 예를 들어 [3]은 대학 캠퍼스 내 다수의 실제 AP에서 장기간 수집한 데이터를 바탕으로 CNN, GRU, LSTM 등 다양한 시계열 모델의 트래픽 예측 성능을 비교하였다. 이러한 연구들은 실제 측정 데이터를 활용한다는 점에서 의의가 있으나, 예측 대상이 트래픽량 자체의 회귀(regression) 문제로 한정되어 있고, 혼잡의 심각도를 판별하는 라벨 체계가 표준 규격에 근거하지 않으며, 제안 모델을 엣지 장비에 배포하여 지연을 실측한 사례도 드물다.

혼잡 수준을 다단계 분류 문제로 정식화하기 위해서는 정답 라벨의 정의가 선행되어야 한다. 그러나 라벨 산정에 사용한 지표를 모델의 입력 feature로 그대로 사용할 경우, 라벨과 입력 사이에 순환적 의존관계(circularity)가 발생하여 모델이 실질적인 패턴을 학습하지 않고도 높은 정확도를 보이는 데이터 누출(leakage) 문제가 발생할 수 있다. 본 연구진은 예비 실험 단계에서 채널 점유율 등 단일 지표에 대한 가중합으로 라벨을 정의하고 이를 모델 입력에 그대로 포함시켰을 때 이러한 순환성이 실제로 발생함을 확인하였으며, 이는 라벨 설계와 모델 입력 설계를 명확히 분리하는 방법론의 필요성을 시사한다.

이에 본 논문은 실제 구매한 상용 AP(GL.iNet Opal, GL-SFT1200)에서 직접 수집한 7종의 시계열 feature를 입력으로 하고, ITU-T Y.1541[4], ITU-T G.114[5], Cisco Enterprise QoS 가이드[6], Aruba WLAN 용량 가이드[7] 등 국제·산업 표준의 문턱값을 앵커(anchor)로 삼아 정의한 4단계 혼잡 라벨을 학습 대상으로 하는 Early-Exit LSTM 기반 혼잡 분류 모델을 제안한다. 라벨 산정에는 별도의 victim 프로브를 통해 측정한 지연·지터·손실률을 사용하되, 이 지표들은 모델 입력에서 제외하여 라벨-입력 간 순환성을 원천적으로 차단하였다. 제안 모델은 Raspberry Pi 상에서 ONNX INT8 양자화 형태로 배포되어 1ms 미만의 실측 추론 지연을 달성하였다.

본 논문의 기여는 다음과 같이 요약된다.

1. 무선 AP의 혼잡·간섭 탐지 문제에 Early-Exit 신경망 구조를 최초로 적용하고, 시뮬레이션이 아닌 실측 데이터와 실제 엣지 장비를 통해 이를 검증하였다.
2. 표준 규격 기반 앵커와 victim 프로브를 결합하되 모델 입력과 라벨 계산 축을 분리함으로써 데이터 누출 문제를 방지하는 라벨링 방법론을 제시하였다.
3. 동일한 백본(backbone) 구조를 공유하는 Baseline, Shallow-Deep Network 재구현 모델, 제안 모델(Early-Exit LSTM)을 통제된 조건에서 비교하여 정확도-효율 간의 트레이드오프를 정량적으로 제시하였다.

본 논문의 구성은 다음과 같다. II장에서는 조기 종료 신경망, 무선랜 혼잡 예측, 엣지 추론과 관련된 선행연구를 검토한다. III장에서는 데이터 수집 환경, 라벨링 방법론, 제안 모델 및 비교 모델의 구조를 기술한다. IV장에서는 실험 설정과 정확도, 심각 등급 탐지 성능, Raspberry Pi 실측 지연 결과를 제시한다. V장에서는 결론과 향후 연구 방향을 논한다.

## II. 관련연구

### 2.1 조기 종료 신경망

Teerapittayanon 등[1]은 심층 신경망의 중간 계층에 다수의 분기(branch)를 추가하고, 각 분기에서 산출된 예측의 엔트로피가 사전에 정한 문턱값보다 낮을 경우 해당 지점에서 추론을 종료하는 BranchyNet을 제안하였다. Kaya 등[2]은 이를 확장하여 내부 분류기에 pooling 기반 구조를 적용하고, 학습 과정에서 깊이에 따라 가중치를 점증적으로 부여하는 커리큘럼 손실 함수와 검증 데이터 기반의 신뢰도 문턱값 보정(calibration) 절차를 결합한 Shallow-Deep Network(SDN)를 제안하여, 정확도 손실을 최소화하면서 평균 추론 비용을 50% 이상 절감할 수 있음을 보였다. 이후 다양한 후속 연구들이 조기 종료 구조를 개선해 왔으나[8], 이들 연구는 공통적으로 이미지 분류를 대상 태스크로 삼고 있으며, 무선 네트워크의 시계열 텔레메트리 데이터에 적용된 사례는 확인되지 않는다.

> ⚠️ **용어 주의**: 여기서의 SDN은 Kaya et al.의 *Shallow-Deep Network* 약자이며, 통신 분야에서 흔히 쓰이는 *Software-Defined Networking*과 무관하다. 본문 전체에서 최초 등장 시 전체 명칭을 병기하고, 이후에도 "SDN(Shallow-Deep Network)" 형태로 유지할 것.

### 2.2 무선랜 혼잡 및 트래픽 예측

무선 네트워크의 트래픽 및 혼잡을 예측하기 위한 딥러닝 연구도 활발히 이루어져 왔다. [3]은 대학 캠퍼스에 설치된 다수의 실제 AP로부터 장기간 수집한 트래픽 데이터를 바탕으로 CNN, 단순 순환 신경망(SRNN), GRU, LSTM, Transformer 등의 시계열 예측 모델을 비교하였으며, LSTM 계열 모델이 반복적 패턴을 갖는 트래픽 예측에 효과적임을 확인하였다. 다만 이러한 연구는 트래픽량 자체를 연속값으로 예측하는 회귀 문제를 다루고 있어, 본 연구와 같이 표준 규격에 기반한 다단계 혼잡 등급을 분류하는 문제와는 태스크 정의가 상이하다. 또한 국내 학술지에서는 무선랜 채널 할당 및 간섭 회피를 다룬 초기 연구들이 보고된 바 있으나[9], 이들 연구는 대체로 규칙 기반(rule-based) 접근에 해당하며, 실측 데이터 기반의 딥러닝 분류 모델을 다룬 국문 연구는 확인되지 않는다.

### 2.3 엣지 환경에서의 경량 추론

엣지 디바이스에서 딥러닝 모델의 추론 지연을 절감하기 위한 방법으로는 양자화(quantization), 가지치기(pruning), 조기 종료 등이 널리 연구되어 왔다[10]. 그러나 이러한 경량화 기법들이 무선랜 혼잡 분류와 같은 네트워크 관리 태스크에 적용되어 Raspberry Pi와 같은 실제 엣지 장비에서 지연을 실측한 연구는 드물며, 본 연구는 이러한 공백을 메우는 것을 목표로 한다.

## III. 시스템 설계

### 3.1 데이터 수집

본 연구는 상용 AP인 GL.iNet Opal(GL-SFT1200)을 대상으로, 유선 SSH 채널을 통해 1Hz 주기로 AP 내부 텔레메트리(채널 점유율, station 통계, 재전송 카운트 등)를 지속적으로 폴링하는 방식으로 데이터를 수집하였다. 관리 트래픽을 무선 채널로부터 분리하기 위해 폴링 및 라벨 계산용 프로브 트래픽은 유선 경로를 통해 별도로 전송하였다. 또한 실제 혼잡 상황을 유발하기 위해 다수의 모바일 단말을 이용한 iperf3 기반 부하를 계단형(step) 및 소패킷(small-packet) 프로파일로 인가하였으며, 최종적으로 2,551개 폴링 샘플을 확보하였다.

### 3.2 라벨링 방법론

혼잡 라벨은 4개의 축 — 채널 점유율, 지터, 손실률, 지연 — 각각에 대해 국제·산업 표준에서 제시하는 문턱값을 4단계 앵커(경고·혼잡·심각·완전)로 삼아 구간 선형(piecewise-linear) 방식으로 [0, 1] 범위의 점수로 정규화한 뒤, 다음과 같이 네 축의 최댓값으로 최종 혼잡 점수를 산정하였다.

```
congestion_score = max(occupancy_score, jitter_score, loss_score, latency_score)
```

산정된 점수는 0.25, 0.50, 0.75를 경계로 정상(0)·경고(1)·혼잡(2)·심각(3) 4단계로 매핑된다. 지터 및 손실률은 부하와 무관하게 유지되는 경량 UDP 프로브(victim probe)의 실측값으로부터, 지연은 ICMP ping RTT의 절반으로부터 산정하였다. 앵커 문턱값은 ITU-T Y.1541의 IP 패킷 지연 변이(IPDV) 등급[4], ITU-T G.114의 편도 지연 등급[5], Cisco Enterprise QoS 가이드의 손실률 기준[6], Aruba WLAN 용량 설계 가이드의 점유율 기준[7]에 각각 근거하였다.

라벨 산정에 사용된 지터·손실률·지연은 모델 입력에서 완전히 배제하였다. 이는 배포 환경에서 모델이 victim 프로브 없이 AP 측 텔레메트리만으로 동작해야 하기 때문이며, 동시에 라벨과 모델 입력 간의 순환적 의존을 차단하기 위한 설계이기도 하다. 또한 단발성 프로브 스파이크로 인한 라벨 잡음을 억제하기 위해, occupancy 축이 심각 수준에 도달하지 않은 상태에서 다른 축만으로 심각 라벨이 부여된 샘플에 대해서는 최근 k회 폴링 중 m회 이상 해당 축이 심각 수준을 유지할 때에만 심각 라벨을 확정하는 지속성 게이트(persistence gate, k=2, m=2)를 적용하였다.

### 3.3 제안 모델: Early-Exit LSTM

제안 모델은 3층 LSTM(hidden size 128, dropout 0.2)을 백본으로 하며, 각 층 뒤에 내부 분류기를 두어 최근 12회 폴링으로 구성된 시계열 윈도우에 대해 조기 종료 여부를 판단한다. 각 내부 분류기의 출력 엔트로피가 문턱값 θ보다 낮으면 해당 지점에서 4단계 혼잡 라벨을 출력하고, 그렇지 않으면 다음 층으로 전파한다. 문턱값 θ는 고정값을 사용하는 Fixed 방식과 최근 트래픽 변동률에 따라 동적으로 조정되는 Dynamic 방식 두 가지로 운용하였다. 학습에는 세 exit 지점의 손실을 0.3:0.3:0.4의 비율로 결합한 다중 종료 손실 함수를 사용하였다.

### 3.4 비교 모델

제안 모델의 상대적 성능을 평가하기 위해 두 가지 비교 모델을 구성하였다. Baseline은 조기 종료 구조 없이 동일한 3층 LSTM 백본의 최종 출력만을 사용하는 모델이다. Shallow-Deep Network(SDN)[2] 비교 모델은 Kaya 등의 원 논문을 충실히 재구현한 것으로, 동일한 백본을 공유하되 (i) max-pooling과 average-pooling을 결합한 내부 분류기 구조, (ii) 깊이에 따라 가중치를 증가시키는 커리큘럼 기반 손실 함수, (iii) 검증 데이터 기반의 신뢰도 문턱값 보정이라는 세 가지 요소에서 제안 모델과 차이를 두었다. 세 모델은 모두 동일한 데이터 분할과 하이퍼파라미터 하에서 5개의 무작위 시드로 학습·평가하였다.

## IV. 실험 및 결과

### 4.1 실험 환경

전체 2,551개 샘플을 시계열 윈도우(길이 12) 단위로 변환한 뒤 학습·검증·시험 집합으로 분할하였으며, 시험 집합은 365개 윈도우(라벨 분포 정상 109·경고 82·혼잡 132·심각 42)로 구성되었다. 각 모델은 5개의 무작위 시드로 학습하였고, 검증 균형 정확도(validation balanced accuracy)가 가장 높은 체크포인트를 최종 평가 및 배포 대상으로 선정하였다.

### 4.2 정확도 및 심각 등급 탐지 성능

5개 시드에 대한 평균 정확도는 Baseline 92.7%(±1.5), SDN 91.9%(±1.0), 제안 모델(Fixed θ) 91.7%(±0.7), 제안 모델(Dynamic θ) 92.3%(±0.7)로, 세 모델 간 정확도는 오차범위 내에서 동등한 수준을 보였다. 반면 가장 판별이 어려운 심각(라벨 3) 등급에 대한 F1 점수는 Baseline 84.3, SDN 86.4, 제안 모델(Fixed) 85.9, 제안 모델(Dynamic) 86.7로, 지속성 게이트 적용 이후 전 모델에서 개선이 관찰되었다(예: 제안 모델의 심각 등급 재현율은 게이트 적용 전 75.2%에서 85.7%로 상승).

| 모델 | 정확도(5-seed) | L3 F1 | Pi 지연(ms) |
|---|---:|---:|---:|
| Baseline (EE 없음) | 92.7±1.5% | 84.3 | 0.864 |
| SDN (Shallow-Deep Network 재구현) | 91.9±1.0% | 86.4 | 0.575 |
| 제안 모델 — Fixed θ | 91.7±0.7% | 85.9 | 0.625 |
| 제안 모델 — Dynamic θ | 92.3±0.7% | 86.7 | 0.632 |

### 4.3 Raspberry Pi 실측 지연

각 모델을 ONNX INT8 형태로 양자화하여 Raspberry Pi에 배포한 뒤 시험 집합 전체에 대해 추론 지연을 실측하였다. 평균 지연은 Baseline 0.864ms, SDN 0.575ms, 제안 모델(Fixed) 0.625ms, 제안 모델(Dynamic) 0.632ms로, 모든 모델이 1ms 미만의 지연을 달성하였다. 특히 제안 모델(Fixed)은 Baseline 대비 28% 낮은 지연을 보였다. Exit 지점별 지연을 분해한 결과, 제안 모델은 모든 exit 단계에서 SDN보다 낮은 지연을 보여 pooling 기반 내부 분류기 대비 구조적으로 경량임을 확인하였다. SDN의 평균 지연이 제안 모델보다 낮게 나타난 것은 구조적 우위가 아니라, 검증 데이터로 보정된 신뢰도 문턱값이 첫 번째 exit의 비중을 상대적으로 높게 설정한 결과로 해석된다.
