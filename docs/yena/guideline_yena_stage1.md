## 2. 생성할 데이터 구조

### 피처 4가지

| 인덱스 | 피처명 | 범위 | 단위 |
|---|---|---|---|
| 0 | 트래픽 양 (RPS) | 0 ~ 1000 | 초당 요청 수 |
| 1 | 채널 점유율 | 0 ~ 100 | % |
| 2 | 패킷 손실률 | 0 ~ 30 | % |
| 3 | 응답 지연 | 0 ~ 500 | ms |

### 레이블 4가지

| 레이블 | 혼잡 수준 | 채널 점유율 기준 |
|---|---|---|
| 0 | 정상 | 40% 미만 |
| 1 | 혼잡 경고 | 40 ~ 65% |
| 2 | 혼잡 | 65 ~ 85% |
| 3 | 심각 혼잡 | 85% 이상 |

### 최종 데이터 shape

```
(샘플 수, 타임스텝, 피처 수) = (N, 10, 4)
```

## 3. 시나리오 4가지

시나리오별로 피처 값의 **범위와 변화 패턴**이 달라야 한다.  
단순 랜덤값이 아니라 실제 공장 운영 흐름을 반영해야 함.

### 시나리오 1 — 일과 시작 (트래픽 급증)

```
07:50  대기 상태
       RPS: 50~100 / 채널 점유율: 10~20% / 손실: 0~1% / 지연: 10~30ms

08:00  라인 가동 시작
       RPS: 50~100 → 400~700 (급증)
       채널 점유율: 10~20% → 50~75%
       패킷 손실률: 0~1% → 5~15%
       응답 지연: 10~30ms → 80~200ms
```

**레이블 흐름:** 0 → 0 → 1 → 2

---

### 시나리오 2 — 긴급 증산 (예측 없는 폭증)

```
14:00  정상 가동
       RPS: 300~500 / 채널 점유율: 35~50% / 손실: 1~3% / 지연: 30~80ms

14:15  긴급 증산 지시
       RPS: 300~500 → 800~1000 (급격히 증가)
       채널 점유율: 35~50% → 85~100%
       패킷 손실률: 1~3% → 20~30%
       응답 지연: 30~80ms → 300~500ms
```

**레이블 흐름:** 0 → 1 → 3

---

### 시나리오 3 — 점심 재가동 (주기적 패턴)

```
12:00  점심 시간 — 최소 트래픽
       RPS: 10~30 / 채널 점유율: 5~10% / 손실: 0% / 지연: 5~15ms

13:00  재가동 시작 — 점진적 증가
       RPS: 10~30 → 100 → 300 → 500 (단계적 증가)
       채널 점유율: 5~10% → 20% → 45% → 65%
```

**레이블 흐름:** 0 → 0 → 1 → 2

> 시나리오 1과 비슷하지만 **점진적** 증가가 핵심. LSTM 시계열 학습 효과 검증에 적합.

---

### 시나리오 4 — 불균형 부하 (특정 AP 과부하)

```
09:00  A라인 정비 시작
       A라인 트래픽 감소
       B, C라인 트래픽 증가 (A 몫이 분산됨)

       특정 AP:
       RPS: 300 → 700 / 채널 점유율: 40% → 80%
       패킷 손실: 2% → 18% / 지연: 50ms → 250ms
```

**레이블 흐름:** 1 → 2 → 3

## 4. 레이블 자동 부여 로직

채널 점유율 기준으로 레이블을 자동 부여한다.

```python
def assign_label(channel_occupancy):
    if channel_occupancy < 40:
        return 0  # 정상
    elif channel_occupancy < 65:
        return 1  # 혼잡 경고
    elif channel_occupancy < 85:
        return 2  # 혼잡
    else:
        return 3  # 심각 혼잡
```

## 5. 슬라이딩 윈도우 전처리

시계열 데이터를 10 타임스텝 단위로 잘라 모델 입력 형태로 만든다.

```
원본 시계열: [t1, t2, t3, ... t100]

윈도우 1: [t1 ~ t10]  → 레이블: t10 기준
윈도우 2: [t2 ~ t11]  → 레이블: t11 기준
윈도우 3: [t3 ~ t12]  → 레이블: t12 기준
...
```

- **윈도우 크기:** 10 타임스텝
- **스트라이드:** 1
- **레이블:** 마지막 타임스텝 기준

## 6. 정규화

각 피처를 0~1 사이로 Min-Max 정규화한다.

```python
X_norm = (X - X_min) / (X_max - X_min)
```

| 피처 | X_min | X_max |
|---|---|---|
| 트래픽 양 (RPS) | 0 | 1000 |
| 채널 점유율 | 0 | 100 |
| 패킷 손실률 | 0 | 30 |
| 응답 지연 | 0 | 500 |

> 정규화 기준값(min, max)은 별도 파일로 저장해둘 것.  
> 나중에 실제 추론 시에도 같은 기준값으로 정규화해야 하기 때문.
