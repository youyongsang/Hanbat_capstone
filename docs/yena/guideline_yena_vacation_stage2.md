# 장예나 방학 2단계 가이드라인
## 실제 WiFi 데이터 수집 및 라벨링

> 담당자: 장예나  
> 목표: 실제 AP 환경에서 WiFi 트래픽 지표를 수집하고 기존 모델 입력 형식의 CSV 데이터셋 생성  
> 완료 기준: `data/real_wifi/train.csv`, `val.csv`, `test.csv` 생성 및 라벨 기준 문서화

---

## 1. 해야 할 일 순서

```
1. AP/Pi 지표 수집 스크립트 실행
2. 정상/경고/혼잡/심각 시나리오별 데이터 수집
3. 원본 데이터를 raw CSV로 저장
4. 기존 모델 입력 피처 형식으로 정리
5. 라벨 0/1/2/3 부여
6. train/val/test 분할
```

---

## 2. 최종 CSV 형식

기존 모델 코드와 호환되도록 아래 컬럼을 기준으로 한다.

```csv
timestamp,rps,channel_occupancy,packet_loss,latency,label
```

| 피처 | 의미 | 수집 또는 계산 방법 |
|---|---|---|
| `timestamp` | 측정 시각 | 수집 루프 기준 시간 |
| `rps` | 요청/패킷 처리량 지표 | iperf3, ping, 패킷 카운터 기반 계산 |
| `channel_occupancy` | 채널 점유율 | `iw dev wlan0 survey dump` 또는 AP 지표 파싱 |
| `packet_loss` | 패킷 손실률 | ping/iperf3 결과 또는 인터페이스 통계 |
| `latency` | 응답 지연 | ping RTT 또는 iperf3 지연 대체 지표 |
| `label` | 혼잡 수준 | 복합 점수 또는 시나리오 기준으로 부여 |

---

## 3. 라벨링 기준

실측 데이터에는 보통 정답 라벨이 없으므로 수집 후 기준을 정해 라벨을 부여한다.

| 라벨 | 의미 | 예시 기준 |
|---:|---|---|
| 0 | 정상 | 낮은 점유율, 낮은 손실률, 낮은 지연 |
| 1 | 혼잡 경고 | 점유율 또는 지연 상승 시작 |
| 2 | 혼잡 | 점유율/손실/지연이 명확히 증가 |
| 3 | 심각 | 다중 단말 고부하, 높은 지연 또는 손실 |

가능하면 단일 피처 하나보다 복합 점수 기준을 사용한다.

```text
congestion_score =
  0.45 * channel_occupancy_score
+ 0.25 * latency_score
+ 0.20 * packet_loss_score
+ 0.10 * rps_score
```

## 4. 시나리오별 수집

| 시나리오 | 단말 구성 | 목표 라벨 |
|---|---:|---:|
| 정상 | 단말 1대 낮은 부하 | 0 |
| 혼잡 경고 | 단말 2~3대 중간 부하 | 1 |
| 혼잡 | 단말 3~4대 고부하 | 2 |
| 심각 | 단말 4대 + 대용량 전송 | 3 |
