## 5. 동적 θ 한계 분석 정리

유용상 결과를 바탕으로 동적 θ 한계를 정리한다.  
보고서의 "한계 및 향후 과제" 섹션에 들어갈 내용이야.

```
현재 규칙 기반 동적 θ의 한계:
- 계산 오버헤드가 Exit 1 종료율 향상 이득을 상쇄
- 시뮬레이터 데이터의 패턴이 명확하여 고정 θ와 정확도 차이 미미

향후 개선 방향:
- 경량 동적 θ 설계 (max-min 범위, 주기적 업데이트)
- 실제 노이즈 환경에서 동적 θ 효과 재검증
```
