# 장예나 방학 1단계 가이드라인
## 실제 WiFi 테스트베드 구성

> 담당자: 장예나  
> 목표: 실제 WiFi 데이터 수집을 위한 동일 테스트베드 구성  
> 완료 기준: GL.iNet AP, Raspberry Pi, 단말 3~4대가 하나의 실험 환경으로 연결됨

---

## 1. 공통 실험 원칙

방학 실측 실험은 환경 편차를 줄이기 위해 한 공간에서 고정된 장비 세트로 진행한다.

| 항목 | 기준 |
|---|---|
| 실험 장소 | 동일 공간에서 고정 수행 |
| AP | GL.iNet OpenWrt AP |
| 엣지 장비 | Raspberry Pi 4 |
| 단말 | 스마트폰 3대 + 노트북 1대 |
| 실험 목적 | 실제 WiFi 트래픽 지표 수집 |

---

## 2. 해야 할 일 순서

```
1. GL.iNet AP 초기 설정
2. Raspberry Pi를 AP LAN 포트에 연결
3. 스마트폰 3대와 노트북 1대를 AP WiFi에 연결
4. AP와 Pi에서 지표 수집 명령 동작 확인
5. 실험 환경 사진 또는 구성도 기록
```

---

## 3. 장비 구성

| 장비 | 역할 |
|---|---|
| GL.iNet AP | 실험용 WiFi AP 및 OpenWrt 지표 수집 대상 |
| Raspberry Pi 4 | 지표 수집, CSV 저장, 추론 실행 환경 |
| 스마트폰 3대 | WiFi 트래픽 생성 단말 |
| 노트북 1대 | 트래픽 생성 또는 SSH/관리용 단말 |
| LAN 케이블 | AP와 Pi 연결 |

---

## 4. 완료 기준 체크리스트

- [ ] GL.iNet AP 관리자 페이지 접속 확인
- [ ] Raspberry Pi와 AP 유선 연결 확인
- [ ] 단말 3~4대가 실험용 WiFi에 접속됨
- [ ] 정상/경고/혼잡/심각 시나리오를 만들 수 있는지 확인
- [ ] 테스트베드 구성도 또는 사진 기록

---

## 5. 주의사항

- 실측 데이터 수집과 실시간 추론은 가능하면 같은 장소에서 진행한다.
- 보고서에는 개인 장소명을 쓰지 말고 "동일 테스트베드"라고 표현한다.
- 장소가 바뀌면 주변 WiFi 간섭이 달라지므로 장비 배치와 장소 조건을 기록한다.
