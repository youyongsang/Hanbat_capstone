# 장예나 방학 1단계 가이드라인
## 실측 실험 환경 준비 및 데이터 수집 기준 확정

> 담당자: 장예나  
> 단계 목표: 실제 WiFi 데이터 수집을 위한 동일 테스트베드와 CSV/라벨 기준 확정  
> 완료 기준: AP/Pi/단말 구성, 수집 피처, 라벨 기준, 시나리오 계획 문서화

---

## 1. 방학 1단계 공통 목표

1단계는 세 명 모두 실제 실험에 들어가기 전 준비 단계다.  
이 단계에서는 아직 본 실험 결과를 만들지 않고, 장비·데이터 형식·실험 기준을 맞춘다.

| 담당 | 1단계 역할 |
|---|---|
| 장예나 | 실측 테스트베드와 데이터 수집/라벨링 기준 확정 |
| 김호중 | Pi 실행 환경과 배포 스크립트 실행 준비 |
| 유용상 | 실측 데이터 입력 형식과 모델 재학습 준비 |

---

## 2. 해야 할 일 순서

```
1. GL.iNet AP, Raspberry Pi, 스마트폰 3대, 노트북 1대 구성 계획 확정
2. AP와 Pi 연결 방식 정리
3. 수집할 피처 확정
4. 라벨 0/1/2/3 의미 확정
5. 정상/경고/혼잡/심각 시나리오 계획 작성
```

---

## 3. 테스트베드 기준

| 항목 | 기준 |
|---|---|
| 실험 장소 | 동일 공간에서 고정 수행 |
| AP | GL.iNet OpenWrt AP |
| 엣지 장비 | Raspberry Pi 4 |
| 단말 | 스마트폰 3대 + 노트북 1대 |
| 데이터 형식 | 기존 모델 입력과 동일한 CSV 형식 |

---

## 4. 최종 CSV 기준

```csv
timestamp,rps,channel_occupancy,packet_loss,latency,label
```

| 라벨 | 의미 |
|---:|---|
| 0 | 정상 |
| 1 | 혼잡 경고 |
| 2 | 혼잡 |
| 3 | 심각 |

---

## 5. 완료 기준 체크리스트

- [ ] 동일 테스트베드 장비 구성 확정
- [ ] 수집 피처 목록 확정
- [ ] 라벨 0/1/2/3 의미 확정
- [ ] 시나리오별 트래픽 생성 계획 작성
- [ ] 호중·용상에게 CSV 형식과 라벨 기준 공유

---

## 6. 주의사항

- 1단계에서는 실제 결과를 만들기보다 기준을 통일하는 것이 목적이다.
- 보고서에는 개인 장소명이 아니라 "동일 테스트베드"라고 표현한다.
- 수집 기준이 바뀌면 호중·용상 단계에도 영향이 있으므로 반드시 공유한다.
