## 2. 8주차 — 보고서 및 발표 자료 완성

### 보고서 담당 섹션

**3장. 데이터 및 실험 환경**

3.1 트래픽 시뮬레이터 설계
- 시뮬레이터 목적 및 구조
- 시나리오 4가지 설명 (표로 정리)
- 노이즈 추가 버전 설명

3.2 실제 WiFi 환경 데이터 수집
- GL.iNet AP 환경 구성 (호중 담당)
- iperf3 트래픽 생성 및 원본 CSV 생성 방법 (호중 담당)
- 원본 CSV 피처를 실험 입력 피처로 변환한 기준 (예나 담당)
- 시뮬레이터 vs 실제 데이터 분포 비교

3.3 데이터셋 구성
- 피처 4개 정의
- 레이블 4개 정의 및 기준
- 샘플 수 및 분포
- 학습/검증/테스트 분할

3.4 전처리 방법
- 슬라이딩 윈도우 (크기 10, 스트라이드 1)
- Min-Max 정규화
- 오프라인 CSV 변환과 실시간 변환에서 동일한 `scaler_params.json` 사용

**5장. 실험 결과 (공동 작성)**

5.1 4개 방식 + SOTA 비교 결과표
5.2 시나리오별 분석 결과
5.3 PC vs Pi 추론 시간 비교표

### 발표 자료 담당 슬라이드

| 슬라이드 | 내용 |

| 데이터 수집 환경 | GL.iNet AP 환경 구성도 |

| 실험 결과 | 비교표 및 그래프 |

## 3. 주의사항

- 보고서 수치는 실험 완료 후 채울 것. 예상값 미리 넣지 않기.
- 시뮬레이터 한계 반드시 명시할 것. "실제 환경과 차이가 있을 수 있다"는 문장 포함.
- 그래프 폰트 크기 발표 슬라이드에서 보일 정도로 충분히 크게 설정할 것.
