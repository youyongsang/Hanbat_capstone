# 장예나 방학 3단계 가이드라인
## 실시간 입력 루프 및 노이즈 시뮬레이터 개선

> 담당자: 장예나  
> 단계 목표: 실제 AP 지표를 실시간 입력 윈도우로 변환하고, 노이즈 추가 시뮬레이터 데이터를 생성  
> 완료 기준: 실시간 `(10, 4)` 입력 윈도우 생성 및 노이즈 시뮬레이터 데이터 전달

---

## 1. 방학 3단계 공통 목표

3단계는 세 명 모두 **수집된 데이터를 이용해 본격 실험을 수행하는 단계**다.  
예나는 실시간 입력과 노이즈 데이터를 만들고, 호중은 Pi/ONNX 측정을 수행하며, 용상은 모델 재학습과 threshold 실험을 수행한다.

| 담당 | 3단계 역할 |
|---|---|
| 장예나 | 실시간 입력 루프 검증, 노이즈 추가 시뮬레이터 생성 |
| 김호중 | ONNX/INT8 변환 및 Pi CSV 추론 측정 |
| 유용상 | LSTM/EE 재학습 및 동적 θ 경량화 실험 |

---

## 2. 실시간 입력 루프

```text
AP 지표 수집
→ 최근 10개 시점 버퍼 저장
→ [rps, channel_occupancy, packet_loss, latency] 윈도우 생성
→ 정규화
→ 모델 입력 형태로 변환
```

### 확인 항목

| 항목 | 확인 내용 |
|---|---|
| 수집 주기 | 1초 또는 고정 간격으로 저장 |
| 윈도우 구성 | 최근 10개 시점이 `(10, 4)` 형태로 구성 |
| 정규화 | 학습 시 사용한 피처 스케일과 일치 |
| 호환성 | 호중 Pi 추론 스크립트 입력과 호환 |

---

## 3. 노이즈 시뮬레이터 개선

```python
channel_occupancy += np.random.normal(0, 5)
packet_loss += np.random.normal(0, 1)
latency += np.random.normal(0, 10)
```

| 비교 대상 | 목적 |
|---|---|
| 기존 시뮬레이터 | 기준선 |
| 노이즈 추가 시뮬레이터 | 실제 환경 변동성 반영 |
| 실제 WiFi 데이터 | 실측 분포 기준 |

---

## 4. 완료 기준 체크리스트

- [ ] 실시간 수집 루프 5분 이상 동작
- [ ] 최근 10개 데이터 윈도우 생성 확인
- [ ] 입력 shape `(10, 4)` 확인
- [ ] 노이즈 추가 시뮬레이터 데이터 생성
- [ ] 실제 WiFi 데이터와 시뮬레이터 데이터 분포 비교
- [ ] 용상에게 노이즈 데이터 전달

---

## 5. 주의사항

- 처음 10개 시점이 쌓이기 전에는 모델 추론이 불가능하다.
- 노이즈 데이터는 기존 데이터를 덮어쓰지 않는다.
- 노이즈 강도는 실측 데이터 분포를 보고 조정한다.
