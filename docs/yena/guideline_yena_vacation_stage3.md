# 장예나 방학 3단계 가이드라인
## 실시간 입력 파이프라인 검증

> 담당자: 장예나  
> 목표: AP 지표를 실시간으로 읽어 모델 입력 윈도우로 변환하는 파이프라인 검증  
> 완료 기준: 최근 10개 시점 데이터가 `(10, 4)` 입력 형태로 생성됨

---

## 1. 해야 할 일 순서

```
1. AP 지표를 주기적으로 읽는 수집 루프 실행
2. 수집값을 [rps, channel_occupancy, packet_loss, latency]로 정리
3. 최근 10개 시점 버퍼 구성
4. 모델 입력 shape 확인
5. 호중 Pi 추론 스크립트 입력 형식과 호환 확인
```

---

## 2. 실시간 처리 흐름

```text
AP 지표 수집
→ 최근 10개 시점 버퍼 저장
→ [rps, channel_occupancy, packet_loss, latency] 윈도우 생성
→ 정규화
→ 모델 입력 형태로 변환
→ 혼잡 수준 추론 가능 상태 확인
```

---

## 3. 확인 항목

| 항목 | 확인 내용 |
|---|---|
| 수집 주기 | 1초 또는 고정 간격으로 지표가 저장되는지 확인 |
| 윈도우 구성 | 최근 10개 시점이 `(10, 4)` 형태로 구성되는지 확인 |
| 정규화 | 학습 시 사용한 피처 스케일과 맞는지 확인 |
| 추론 연결 | 호중이 제공한 Pi 추론 스크립트에 입력 가능한지 확인 |

---

## 4. 완료 기준 체크리스트

- [ ] 실시간 수집 루프가 5분 이상 중단 없이 동작
- [ ] 수집 로그가 CSV로 저장됨
- [ ] 최근 10개 데이터 윈도우 생성 확인
- [ ] 입력 shape `(10, 4)` 확인
- [ ] 호중의 Pi 추론 스크립트와 입력 형식 호환 확인

---

## 5. 주의사항

- 처음 10개 시점이 쌓이기 전에는 모델 추론이 불가능하다.
- 실시간 데모는 정확도 비교보다 시스템 동작 가능성 검증으로 해석한다.
- 실시간 로그는 추후 호중의 배포 실험과 연결될 수 있도록 저장한다.
