> 완료 기준: 담당 보고서 섹션 완성, 발표용 그래프 최종본 전달

## 2. 보고서 담당 섹션

### 3장. 데이터 및 실험 환경

**3.1 트래픽 시뮬레이터 설계**
- 시뮬레이터 목적 및 구조
- 시나리오 4가지 설명 (표로 정리)
- 수식 기반 모사 방법 및 한계 명시

**3.2 데이터셋 구성**
- 피처 4개 정의 (RPS, 채널 점유율, 패킷 손실률, 응답 지연)
- 레이블 4개 정의 및 기준
- 샘플 수 및 분포 (표로 정리)
- 학습/검증/테스트 분할 비율

**3.3 전처리 방법**
- 슬라이딩 윈도우 (크기 10, 스트라이드 1)
- Min-Max 정규화 기준값 및 적용 방법

### 5장. 실험 결과

**5.1 4개 방식 비교**
- 전체 정확도 비교표
- 추론 시간 비교표
- Exit 종료율 비교 (③, ④)

**5.2 시나리오별 분석**
- 시나리오별 정확도 비교표
- 주요 발견사항 서술

**5.3 경량화 및 Pi 배포 결과**
- PC vs Pi 추론 시간 비교표
- 모델 크기 변화

## 3. 발표용 그래프 최종본

5단계에서 만든 그래프를 발표 슬라이드에 맞게 정리.

| 그래프 | 용도 |
|---|---|
| 4개 방식 정확도 비교 | 핵심 결과 슬라이드 |
| 정확도 vs 추론 시간 산점도 | Early Exit 효과 강조 슬라이드 |
| Exit 종료율 비교 | 동적 θ 분석 슬라이드 |
| 시나리오별 정확도 | 시나리오 분석 슬라이드 |
| PC vs Pi 추론 시간 | 배포 결과 슬라이드 |

## 5. 주의사항

- 보고서 수치는 실험 결과 그대로 쓸 것. 좋게 보이려고 수정하지 않기.
- 시뮬레이터 한계 반드시 명시할 것. "실제 환경과 차이가 있을 수 있다"는 문장 포함.
- 그래프 폰트 크기 발표 슬라이드에서 보일 정도로 충분히 크게 설정할 것.
