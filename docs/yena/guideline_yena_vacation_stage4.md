# 장예나 방학 4단계 가이드라인
## 노이즈 추가 시뮬레이터 개선 및 데이터 비교

> 담당자: 장예나  
> 목표: 기존 시뮬레이터 데이터에 현실적인 노이즈를 추가하고 실제 WiFi 데이터와 분포 비교  
> 완료 기준: 노이즈 추가 시뮬레이터 데이터셋과 실제 WiFi 데이터 분포 비교표 완성

---

## 1. 해야 할 일 순서

```
1. 기존 시뮬레이터 데이터 구조 확인
2. 채널 점유율, 패킷 손실률, 지연시간에 노이즈 추가
3. 기존 시뮬레이터와 노이즈 추가 버전 분리 저장
4. 실제 WiFi 데이터와 피처 분포 비교
5. 용상 동적 threshold 재실험용 데이터 전달
```

---

## 2. 노이즈 추가 예시

```python
channel_occupancy += np.random.normal(0, 5)
packet_loss += np.random.normal(0, 1)
latency += np.random.normal(0, 10)
```

---

## 3. 비교 항목

| 비교 대상 | 확인 내용 |
|---|---|
| 기존 시뮬레이터 | 너무 깔끔한 패턴인지 확인 |
| 노이즈 추가 시뮬레이터 | 실제 환경에 가까운 변동성 확보 여부 |
| 실제 WiFi 데이터 | AP 기반 실측 분포 |

---

## 4. 완료 기준 체크리스트

- [ ] 기존 시뮬레이터와 노이즈 추가 시뮬레이터 분리
- [ ] 실제 WiFi 데이터와 피처 분포 비교
- [ ] 노이즈 추가 전후 데이터 분포표 작성
- [ ] 용상 동적 threshold 재실험용 데이터 전달
- [ ] 보고서용 데이터 생성 과정 정리

---

## 5. 주의사항

- 노이즈 추가 데이터는 기존 데이터와 덮어쓰지 않는다.
- 실제 데이터와 시뮬레이터 데이터 결과는 반드시 분리해서 해석한다.
- 노이즈 강도는 임의로 과도하게 키우지 말고 실측 데이터 분포를 보고 조정한다.
