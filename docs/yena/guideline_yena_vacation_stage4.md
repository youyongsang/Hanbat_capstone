# 장예나 방학 4단계 가이드라인
## 데이터 결과 정리 및 실시간 데모 지원

> 담당자: 장예나  
> 단계 목표: 실측 데이터셋, 실시간 입력 로그, 노이즈 데이터 결과를 정리하고 최종 데모를 지원  
> 완료 기준: 데이터 수집 결과표와 실시간 입력 로그 요약 문서 완성

---

## 1. 방학 4단계 공통 목표

4단계는 세 명 모두 **최종 분석·데모·공유 단계**다.  
새 실험을 계속 늘리기보다, 1~3단계에서 나온 결과를 한 흐름으로 묶어 정리한다.

| 담당 | 4단계 역할 |
|---|---|
| 장예나 | 데이터셋/실시간 입력/노이즈 데이터 결과 정리 |
| 김호중 | Pi 배포 결과와 실시간 혼잡 판단 데모 정리 |
| 유용상 | PC 모델 결과와 Pi 결과 연결 분석 |

---

## 2. 정리 항목

| 항목 | 정리 내용 |
|---|---|
| 실측 데이터셋 | 샘플 수, 라벨 분포, 시나리오별 구성 |
| 실시간 입력 로그 | 수집 주기, 윈도우 생성 여부, 오류 여부 |
| 노이즈 데이터 | 기존 시뮬레이터 대비 분포 변화 |
| 공유 자료 | 호중 Pi 실험용 데이터, 용상 모델 실험용 데이터 |

---

## 3. 완료 기준 체크리스트

- [ ] 실측 데이터셋 요약표 작성
- [ ] 라벨 분포표 작성
- [ ] 실시간 입력 루프 로그 정리
- [ ] 노이즈 시뮬레이터 비교표 작성
- [ ] 호중·용상에게 최종 데이터셋 전달
- [ ] 보고서용 데이터 수집 과정 정리

---

## 4. 주의사항

- 실시간 데모 결과와 CSV 기반 정량 평가를 혼동하지 않는다.
- 데이터 수집 조건을 반드시 기록한다.
- 실측 데이터의 한계도 함께 적는다.
