## 1. 4개 방식 최종 비교 실험 개요

2단계에서 구성한 통합 실험 프레임워크를 바탕으로 최종 성능 평가를 수행하였다. 모든 비교 대상 모델은 동일한 Kaggle 6G 실제 데이터셋(Kaggle – 6G Network Slicing QoS Dataset) 기반의 테스트 데이터로 평가되었으며, 공정한 성능 검증을 위해 추론 시간은 순수 CPU 연산 환경에서 측정되었다.

### 1) 비교 대상 모델 개요
* ① 임계값 방식: 복합 혼잡 점수 기준의 Rule-based 판정 알고리즘
* ② 일반 LSTM: 표준 3-Layer LSTM 모델 (Early Exit 미적용)
* ③ Early Exit + 고정 θ: 정적 임계값 규칙 기반의 조기 종료 알고리즘 적용 모델
* ④ 제안 모델 (동적 θ): 실시간 트래픽 변동성(Variance) 감지 기반 경량 동적 임계값 조기 종료 알고리즘 적용 모델

### 2) 평가 지표 정의
* 전체 정확도 (%): 전체 테스트 데이터셋 대비 모델의 예측 성공 비율
* 레이블별 정확도 (%): 정상(L0), 혼잡 경고(L1), 혼잡(L2), 심각 혼잡(L3) 상태별 개별 감지 정확도
* 평균 추론 시간 (ms): CPU 연산 장치 기준 단일 샘플 추론 소요 시간
* Exit별 종료율 (%): Early Exit 모델(③, ④) 내부의 레이어별 조기 탈출 수행 비율
* 불필요 채널 전환율 (%): 트래픽 오판으로 인해 정상 구간에서 잘못된 채널 스위칭 오버헤드가 발생한 비율

## 3. 시나리오별 분석

test_with_scenario.csv 데이터를 연계하여 총 4가지 무선 네트워크 운용 환경 시나리오별 혼잡 감지 정확도를 분리 분석하였다.

### 1) 시나리오별 세부 정확도 지표

* 일과 시작 (점진적 급증 - startup_surge)
  - 일반 LSTM ②: 93.3%
  - EE 고정 θ ③: 97.1%
  - EE 동적 θ ④: 97.1%
  - 분석 결과: 트래픽이 서서히 누적 증가하는 문맥 패턴 환경에서, 제안하는 동적 θ 방식이 97.1%로 일반 LSTM(93.3%) 대비 우수한 성능으로 혼잡 여부를 선별해냈다. 이는 점진적 증가세 속에서 임계값 알고리즘이 안정 상태 규칙(Stable Rule)을 유연하게 매핑하여 조기 종료 선별력을 최적화했음을 시사한다.

* 긴급 증산 (갑작스러운 폭증 - emergency_ramp)
  - 일반 LSTM ②: 91.6%
  - EE 고정 θ ③: 92.8%
  - EE 동적 θ ④: 92.8%
  - 분석 결과: 트래픽이 비연속적이고 수직으로 급증하는 긴급 상황 환경에서는 일반 LSTM(91.6%)보다 Early Exit 구조 기반 모델들이 신속 정확도를 보였다. 특히 제안 모델군들은 갑작스러운 폭증 자극에도 흔들리지 않고 안정적인 정확도 방어력을 보여, 실시간 변동성 감지를 통한 임계값 스케일링의 이점을 증명한다.

* 점심 재가동 (주기적 패턴 - lunch_restart)
  - 일반 LSTM ②: 94.0%
  - EE 고정 θ ③: 100.0%
  - EE 동적 θ ④: 100.0%
  - 분석 결과: 정해진 타임라인에 부하가 밀집되는 주기성 시나리오에서는 규칙 기반 알고리즘①(전체 정확도 42.2%) 대비 순수 시계열 딥러닝 백본 모델군이 모두 94% 이상의 압도적인 방어력을 나타냈으며, 특히 Early Exit 적용 시 100.0%의 완벽한 예측을 달성했다. 이는 딥러닝 순환 신경망이 무선 자원 요구량의 시간적 연속 주기를 정확히 학습했음을 뒷받침한다.

* 불균형 부하 (지속적 혼잡 - imbalanced_ap_load)
  - 일반 LSTM ②: 92.5%
  - EE 고정 θ ③: 97.5%
  - EE 동적 θ ④: 97.5%
  - 분석 결과: 엣지 AP 자원 불균형으로 인해 부하 상태가 지속 유지되는 구간에서는 제안 동적 θ 알고리즘이 97.5%로 일반 LSTM(92.5%) 대비 판정 효율을 한 단계 더 개선하였다. 변동성이 일시적으로 낮아진 장기 지속 부하 상태에서는 제안 모델이 과도한 연산 낭비 없이 안정적인 예측치를 고수하여 성능 우위를 가졌다.

## 4. 핵심 비교 포인트 결론

### 1) 임계값 ① vs 일반 LSTM ②
과거 데이터의 시계열 문맥을 고려하지 않고 현재 시점의 단편 수치만 필터링하는 규칙 기반 임계값 방식(42.2%)은 복합적인 6G 망 환경 방어가 불가능하다. 반면 슬라이딩 윈도우 기반 히스토리를 파악하는 일반 LSTM 모델을 전개할 경우, 전체 혼잡도 판정 정확도가 50.7%p 폭증하는 쾌거를 이루어 데이터 내 시계열 패턴 학습의 절대적 필요성을 명확히 증명하였다.

### 2) 일반 LSTM ② vs Early Exit ③
Early Exit 네트워크 매커니즘은 3개 층의 딥러닝 연산을 끝까지 거치는 일반 LSTM(92.9%) 대비 전체 정확도를 저해하지 않고 오히려 96.9%로 상회하며 긴밀하게 방어해냈다. 동시에 테스트 샘플의 약 91.7%(Exit 1: 17.9% + Exit 2: 73.8%)를 최종 연산(Exit 3) 이전에 연산 차단 및 조기 종료 시킴으로써 자원 제약적인 6G 무선 인프라에서 정확성과 초저지연성을 동시 확보 가능함을 입증하였다.

### 3) Early Exit 고정 θ ③ vs 동적 θ ④
고정형 임계값 방식(③)에서 실시간 윈도우 기반 트래픽 변동성을 연계한 경량 동적 임계값 방식(④)으로 선회 시, 전체 감지 정확도를 96.9% 동등 수준으로 유지하는 우수성을 거두었다. 아울러 동적 스케일링 규칙에 따라 안정적인 트래픽 하에서는 하위 탈출구 사용률을 증가시켜(Exit 1 비율 17.9%에서 21.7%로 확장), 결과적으로 연산량이 가장 가중되는 최종장(Exit 3) 진입 비율을 8.3%에서 5.4%로 대폭 억제하는 고효율 망 관리 유연성을 달성하였다.

## 5. 불필요 채널 전환 분석

정상 구간(label=0)에서 전환 명령이 발생한 경우를 분석한다.

```python
# 정상 구간에서 전환 발생 비율
normal_samples = test_data[test_data['true_label'] == 0]
unnecessary_switches = normal_samples[normal_samples['predicted_label'] != 0]
rate = len(unnecessary_switches) / len(normal_samples) * 100
```
### 1) ① 임계값 방식 (Threshold)
* `len(normal_samples)` (실제 정상 샘플 개수): 56개
* `len(unnecessary_switches)` (혼잡으로 오판한 개수): 8개
* `rate` (최종 불필요 전환율): (8 / 56) * 100 = 14.29%

### 2) ② 일반 LSTM
* `len(normal_samples)` (실제 정상 샘플 개수): 56개
* `len(unnecessary_switches)` (혼잡으로 오판한 개수): 4개
* `rate` (최종 불필요 전환율): (4 / 56) * 100 = 7.14%

### 3) ③ Early Exit + 고정 θ
* `len(normal_samples)` (실제 정상 샘플 개수): 56개
* `len(unnecessary_switches)` (혼잡으로 오판한 개수): 3개
* `rate` (최종 불필요 전환율): (3 / 56) * 100 = 5.36%

### 4) ④ 제안 모델 (Early Exit + 동적 θ)
* `len(normal_samples)` (실제 정상 샘플 개수): 56개
* `len(unnecessary_switches)` (혼잡으로 오판한 개수): 3개
* `rate` (최종 불필요 전환율): (3 / 56) * 100 = 5.36%
