## 2. 4개 방식 최종 비교 실험

2단계에서 구성한 프레임워크로 최종 실험 수행.  
모든 방식을 **동일한 테스트 데이터**로 평가한다.

### 비교 대상

| 번호 | 방식 | 비고 |
|---|---|---|
| ① | 임계값 방식 | 2단계에서 구현 완료 |
| ② | 일반 LSTM | 2단계에서 학습 완료 |
| ③ | Early Exit + 고정 θ | 유용상 제공 |
| ④ | 제안 모델 (동적 θ) | 유용상 제공 |

### 평가 지표

| 지표 | 설명 |
|---|---|
| 전체 정확도 (%) | 전체 테스트셋 기준 |
| 레이블별 정확도 | 0~3 각각 따로 측정 |
| 평균 추론 시간 (ms) | CPU 기준, 100회 평균 |
| Exit별 종료율 (%) | ③, ④만 해당 |
| 불필요 채널 전환율 (%) | 정상 구간에서 전환 발생 비율 |

## 4. 시나리오별 분석

장예나가 제공한 `test_with_scenario.csv`를 사용하여  
시나리오별로 분리해서 분석한다.

### 분석 항목

| 시나리오 | 분석 목적 |
|---|---|
| 일과 시작 (점진적 급증) | LSTM이 점진적 패턴을 임계값 대비 얼마나 잘 잡는지 |
| 긴급 증산 (갑작스러운 폭증) | 급변 시 4개 방식의 반응 속도 차이 |
| 점심 재가동 (주기적 패턴) | 주기 패턴 학습 효과 확인 |
| 불균형 부하 (지속적 혼잡) | 혼잡 지속 구간 정확도 비교 |

### 핵심 비교 포인트

**임계값 ① vs 일반 LSTM ②**
→ LSTM이 시계열 패턴을 학습했을 때 임계값 대비 얼마나 좋아지는지

**일반 LSTM ② vs Early Exit ③**
→ Early Exit이 정확도 유지하면서 추론 시간을 얼마나 줄이는지

**Early Exit 고정 θ ③ vs 동적 θ ④**
→ 동적 threshold가 급변 구간에서 얼마나 효과적인지

## 5. 불필요 채널 전환 분석

정상 구간(label=0)에서 전환 명령이 발생한 경우를 분석한다.

```python
# 정상 구간에서 전환 발생 비율
normal_samples = test_data[test_data['true_label'] == 0]
unnecessary_switches = normal_samples[normal_samples['predicted_label'] != 0]
rate = len(unnecessary_switches) / len(normal_samples) * 100
```

임계값 방식은 채널 점유율만 보기 때문에  
정상이지만 일시적으로 점유율이 높은 순간에 불필요한 전환이 발생할 수 있다.  
LSTM은 시계열 패턴으로 이를 구분할 수 있어 불필요 전환이 줄어들 것으로 예상.

## 7. 주의사항

- 추론 시간은 반드시 **CPU 기준**으로 측정. GPU 쓰면 안 됨.
- 동일한 테스트 데이터로 4개 방식 모두 평가할 것. 데이터가 다르면 비교가 무의미함.
- ③, ④ 모델은 유용상한테 받아서 쓸 것. 직접 구현하지 않음.
- 결과가 예상과 다르게 나와도 그대로 기록할 것. 분석이 중요함.
