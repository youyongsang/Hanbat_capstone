# 김호중 방학 5단계 가이드라인
## Pi 배포 결과 분석 및 팀 공유

> 담당자: 김호중  
> 목표: Raspberry Pi 실측 결과를 분석하고 용상·예나 작업과 연결  
> 완료 기준: FP32/INT8, fixed/dynamic, CSV/실시간 결과 비교표 완성

---

## 1. 해야 할 일 순서

```
1. Pi 결과 CSV 분석
2. FP32 vs INT8 비교표 작성
3. fixed vs dynamic 비교표 작성
4. CSV 평가와 실시간 데모 결과 분리 정리
5. 용상·예나에게 결과 공유
```

---

## 2. 정리 표

| 비교 | 포함 항목 |
|---|---|
| FP32 vs INT8 | 모델 크기, 정확도, 평균 추론 시간 |
| fixed vs dynamic | 정확도, 지연, Exit 비율 |
| CSV 평가 vs 실시간 데모 | 정량 평가와 동작 검증 분리 |
| PC vs Pi | 같은 데이터 기준 추론 시간 차이 |

---

## 4. 주의사항

- Pi 결과는 실행 환경 영향을 받으므로 반복 측정 평균과 p95를 함께 제시한다.
- INT8이 항상 더 빠르거나 정확도가 높은 것은 아니다.
- 호중 담당 산출물은 Pi 배포 코드와 실측 결과이며, 데이터 라벨링 기준은 예나 문서를 따른다.
