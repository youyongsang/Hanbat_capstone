# 김호중 방학 2단계 가이드라인
## 실측 데이터 반영 및 Pi 배포 입력 준비

> 담당자: 김호중  
> 단계 목표: 예나가 만든 실측 CSV를 Pi 배포 환경에서 읽을 수 있도록 준비  
> 완료 기준: 실측 `test.csv`가 Pi 배포 폴더에서 로딩 가능

---

## 1. 방학 2단계 공통 목표

2단계는 세 명 모두 **실측 데이터 기반 실험에 들어갈 입력을 확보하는 단계**다.  
예나는 데이터를 만들고, 호중은 Pi에서 읽을 준비를 하며, 용상은 모델 입력으로 변환되는지 확인한다.

| 담당 | 2단계 역할 |
|---|---|
| 장예나 | 실제 WiFi 데이터 수집 및 train/val/test 생성 |
| 김호중 | 수집 데이터의 Pi 배포 폴더 반영 및 실행 파일 준비 |
| 유용상 | 수집 데이터의 dataloader 호환성 검증 |

---

## 2. 해야 할 일 순서

```
1. 예나가 공유한 data/real_wifi/test.csv 수령
2. Pi 배포 폴더에 test.csv 배치
3. CSV 컬럼 형식 확인
4. inference_pi.py에서 파일 로딩 확인
5. ONNX 변환/배포 명령어 준비
```

---

## 3. 확인 항목

| 항목 | 기준 |
|---|---|
| CSV 컬럼 | `timestamp`, `rps`, `channel_occupancy`, `packet_loss`, `latency`, `label` |
| 라벨 | 0/1/2/3 |
| 입력 피처 | 4개 피처 유지 |
| 배포 폴더 | Pi에서 바로 읽을 수 있는 위치 |

---

## 4. 완료 기준 체크리스트

- [ ] 실측 `test.csv` 수령
- [ ] Pi 배포 폴더에 데이터 반영
- [ ] CSV 로딩 테스트 완료
- [ ] 실행 명령어 초안 작성
- [ ] 용상 최종 모델 코드 반영 여부 확인

---

## 5. 주의사항

- 2단계에서는 Pi 성능 측정을 본격 수행하지 않는다.
- 데이터 형식이 맞지 않으면 예나와 먼저 형식을 맞춘다.
- 체크포인트와 ONNX 파일은 각 환경에서 생성하는 것을 원칙으로 한다.
