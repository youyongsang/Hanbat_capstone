# 더미 데이터 명세서
## 경량 Early Exit 딥러닝을 이용한 산업 무선망 트래픽 혼잡 감지 및 채널 최적화

> 작성자: 유용상  
> 목적: 베이스라인 LSTM 및 Early Exit LSTM 개발을 위한 임시 더미 데이터 스펙 정의  
> 상태: 장예나의 트래픽 시뮬레이터 완성 전까지 사용. 완성 후 실제 데이터로 교체.

---

## 1. 데이터 구조

```
shape: (샘플 수, 타임스텝, 피처 수)
     = (1000, 10, 4)
```

| 항목 | 값 | 설명 |
|---|---|---|
| 샘플 수 | 1000 | 전체 데이터 수 |
| 타임스텝 | 10 | 슬라이딩 윈도우 크기. 10 타임스텝 = 100ms 구간 |
| 피처 수 | 4 | 트래픽 혼잡 판단에 사용할 수치 4가지 |

---

## 2. 피처 정의

| 인덱스 | 피처명 | 범위 | 단위 | 설명 |
|---|---|---|---|---|
| 0 | 트래픽 양 (RPS) | 0 ~ 1000 | 초당 요청 수 | 해당 AP로 들어오는 초당 요청량 |
| 1 | 채널 점유율 | 0 ~ 100 | % | 무선 채널이 사용 중인 비율 |
| 2 | 패킷 손실률 | 0 ~ 30 | % | 전송 실패한 패킷 비율 |
| 3 | 응답 지연 | 0 ~ 500 | ms | 요청 후 응답까지 걸리는 시간 |

> **주의:** 더미 데이터는 NumPy 랜덤값으로 생성하되, 레이블과 피처 간 상관관계를 반영해야 함.  
> 예: 레이블 3(심각)이면 채널 점유율은 85 이상, 패킷 손실률은 높게 생성.

---

## 3. 레이블 정의

| 레이블 | 의미 | 채널 점유율 기준 | 대응 방안 |
|---|---|---|---|
| 0 | 정상 | 40% 미만 | 채널 유지 |
| 1 | 혼잡 경고 | 40 ~ 65% | 모니터링 강화, 전환 준비 |
| 2 | 혼잡 | 65 ~ 85% | 덜 혼잡한 채널로 전환 |
| 3 | 심각 혼잡 | 85% 이상 | 즉시 채널 전환 또는 5GHz 이동 |

---

## 4. 샘플 분포

| 레이블 | 샘플 수 | 비율 | 설정 근거 |
|---|---|---|---|
| 0 (정상) | 600 | 60% | 공장 정상 가동 구간이 가장 많음 |
| 1 (혼잡 경고) | 200 | 20% | 라인 가동 시작·재가동 구간 |
| 2 (혼잡) | 150 | 15% | 긴급 증산·풀가동 구간 |
| 3 (심각) | 50 | 5% | 드물게 발생하는 극단적 상황 |
| **합계** | **1000** | **100%** | |

---

## 5. 데이터 분할

| 용도 | 샘플 수 | 비율 |
|---|---|---|
| 학습 (Train) | 700 | 70% |
| 검증 (Validation) | 150 | 15% |
| 테스트 (Test) | 150 | 15% |

> 분할 시 레이블 비율이 유지되도록 **Stratified Split** 적용 권장.

---

## 6. 전처리 방법

### 정규화
각 피처를 0~1 사이로 **Min-Max 정규화** 적용.

```
X_norm = (X - X_min) / (X_max - X_min)
```

| 피처 | X_min | X_max |
|---|---|---|
| 트래픽 양 | 0 | 1000 |
| 채널 점유율 | 0 | 100 |
| 패킷 손실률 | 0 | 30 |
| 응답 지연 | 0 | 500 |

### 슬라이딩 윈도우
- 윈도우 크기: 10 타임스텝
- 스트라이드: 1
- 각 윈도우의 마지막 타임스텝 기준으로 레이블 부여

---

## 7. 더미 데이터 생성 가이드

레이블별로 피처 범위를 다르게 설정해서 현실적인 패턴을 만들어야 해.

| 레이블 | 트래픽 양 (RPS) | 채널 점유율 (%) | 패킷 손실률 (%) | 응답 지연 (ms) |
|---|---|---|---|---|
| 0 (정상) | 0 ~ 400 | 0 ~ 40 | 0 ~ 2 | 0 ~ 50 |
| 1 (혼잡 경고) | 400 ~ 650 | 40 ~ 65 | 2 ~ 8 | 50 ~ 150 |
| 2 (혼잡) | 650 ~ 850 | 65 ~ 85 | 8 ~ 20 | 150 ~ 300 |
| 3 (심각) | 850 ~ 1000 | 85 ~ 100 | 20 ~ 30 | 300 ~ 500 |

> 단순 랜덤값이 아니라 레이블에 맞는 범위에서 생성해야  
> 모델이 의미있는 패턴을 학습할 수 있음.

---

## 8. 실제 데이터 교체 시 주의사항

장예나의 트래픽 시뮬레이터 완성 후 더미 데이터를 실제 데이터로 교체할 때:

- `shape: (N, 10, 4)` 동일하게 유지
- 레이블 0~3 동일하게 유지
- 정규화 기준값(min, max)은 실제 데이터 기준으로 재계산
- 학습/검증/테스트 분할 비율 동일 유지 (70/15/15)
