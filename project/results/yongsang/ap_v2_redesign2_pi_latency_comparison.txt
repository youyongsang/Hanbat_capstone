=== 4차 (2026-08-30 후속) — Baseline·SDN 5시드 특성화 ===

Proposed EE만 5시드로 특성화했던 걸 Baseline·SDN도 동일하게(power=0.0, 시드 0~4):

| 모델 | 5시드 test 정확도 | Label3 F1 | Label3 recall | val-best seed | 비고 |
|---|---:|---:|---:|---|---|
| Baseline   | 92.0% ±0.7 | 66.1% ±2.3 | 54.2% ±3.8 | **seed3 (val bal 89.0%)** | 기존 배포 seed0에서 교체 |

| EE Fixed θ | 90.7% ±0.7 | 64.5% ±5.5 | 51.0% ±6.6 | seed4 (동률 중 F1 tiebreak) | 배포 그대로 |

- **Baseline 배포 체크포인트 교체: seed0 → seed3.** seed0(val bal 87.8%)은 val-best가 아니었고 test 92.3%는 운 좋은 draw였음. seed3(val bal 89.0%, test 91.6%, L3 F1 65.5%)가 정직한 selector로는 배포 대상. ONNX 재수출·Pi 재측정 완료 — Pi INT8 0.746ms(seed0의 0.739와 오차범위, Baseline은 weight 무관 항상 3층).
- **세 모델 5시드 평균이 거의 겹침** (92.0 / 90.4 / 90.7%, 전부 ±0.7). Baseline이 평균으로도 근소 1위지만 SDN·EE와의 차이(~1.5pt)는 시드 std 두 배 수준 — "Baseline이 확실히 낫다"보다 "셋이 비슷한데 Baseline이 약간 앞"이 정확한 서술. Label3 F1은 셋 다 64~66%로 사실상 동률.
- SDN·EE는 배포 체크포인트 안 바뀜(val-best 그대로). SDN 재수출·재측정 불필요.

power=1.0 -> 0.0 지연 변화: Baseline 0.756->0.739(≈동일, 항상 3층), SDN 0.636->0.534,
Proposed Fixed 0.641->0.540(-16%), Dynamic 0.645->0.555(-14%). EE가 빨라진 이유는 명확 —
power=1.0은 exit3 도달률이 52%였는데 power=0.0은 19%(Fixed)/10%(Dynamic)로 훨씬 일찍 빠짐
(라벨3 과보호가 없어지면서 뒤 exit로 미루는 경향이 줄었음). Pi 실측 exit 분포가 fp32 eval과
정확히 일치(30.3/50.3/19.4 vs 30.0/50.6/19.4).

=== 5차 (2026-08-30 후속2) — SDN 논문 충실 재구현 ===

기존 "SDN-style"은 Proposed와 백본이 100% 같아 "다른 모델과의 비교"가 아니라 "같은 모델 다른 규칙"
이었음. Kaya et al. (Shallow-Deep Networks, ICML 2019) 논문/공식 코드대로 재구현:
- **Internal Classifier**: `alpha·maxpool + (1-alpha)·avgpool` (timestep 전체, alpha 학습) → Linear.
  (Proposed: 마지막 timestep → Linear)
- **loss 가중**: 커리큘럼 램프 `cur = min(mc, 0.01 + epoch·mc/50)`, `mc = [0.15, 0.30]`, 최종 분류기 1.0.
  (Proposed: 고정 균등 0.3/0.3/0.4)
- **confidence threshold**: val에서 스윕해 "full-network 정확도 −1% 이내 최소 비용" 운영점 선택.
  (Proposed: entropy θ 고정 또는 트래픽 변동 적응)
- base 3층 LSTM·epochs·batch·lr·class-weight-power는 EE와 동일(통제 변수).

| 모델 | Pi INT8(ms) | 5시드 정확도 | 5시드 L3 F1 | 배포(val-best) |
|---|---:|---:|---:|---|
| SDN (논문 충실)   | **0.572** | 90.4% ±1.4 | **60.4% ±8.1** | seed3 · T=0.80 · test 90.3% / L3 F1 65.3% |
| Proposed EE Fixed | 0.540 | 90.7% ±0.7 | 64.5% ±5.5 | seed4 · test 90.6% / L3 F1 68.0% |

해석 (5차 반영):
- **4개 모델 전부 목표2(<1ms) 달성.** Baseline 0.75 / SDN 0.57 / Proposed 0.54~0.56ms.
- **정확도는 셋이 겹침** (5시드 평균 Baseline 92.0 / SDN 90.4 / Proposed 90.7%). 갈리는 두 축:
  1. **label3 안정성** — SDN 논문 충실은 F1 60.4%±**8.1**(편차 2배), 시드별 캘리브레이션 T가
     0.71~0.86으로 요동. Proposed는 64.5%±5.5로 더 안정. 작은 val에서 per-model 캘리브레이션이 취약.
  2. **속도** — SDN pooling IC(ReduceMax+Mean per exit)가 Proposed의 last-timestep linear보다 무거움
     → 0.572 vs 0.540ms. Proposed가 -6%.
- **발표 프레이밍**: "기존 조기종료 방법(SDN)과 동급 정확도 + 더 가벼운 exit head + 희소클래스에서
  더 안정적 + 트래픽 적응형 임계값." "SDN을 이겼다"가 아니라 "우리 설계 선택의 효과".
- Baseline은 정확도 근소 1위지만 EE 없음(항상 3층, 0.75ms). Proposed의 가치는 속도·연산량(구조상 ~절반).

`*_6feat_archived_20260829.*` 및 `checkpoints/ap_v2_redesign2_6feat_archived_20260829/`,
`data/ap_metrics_v2_redesign2_6feat_archived_20260829/`, Pi `~/ap_pi_v2/archived_6feat_20260829/`에
전부 보존.

학습 파이프라인에 `--seed` 옵션 신규 추가(`train_ap_early_exit.py`/`train_ap_sdn.py`/
`train_ap_baseline_lstm.py`) — 그 전까지 시드 고정이 전혀 없어 단일 실행 A/B 비교가
신뢰할 수 없었음(같은 6-feature+SDN 가중치 설정을 시드만 바꿔 재실행하면 test 정확도가
